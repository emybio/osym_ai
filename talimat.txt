---------------------------------------------------------------------
1) ENV DOSYALARI – DEĞİŞTİRİLEMEZ YAPI
---------------------------------------------------------------------

Backend içinde bulunan ENV dosyaları:

backend/.env.office.dev      ✅ (Ofis - Development - Django server)
backend/.env.office.prod     ✅ (Ofis - Production - Docker)
backend/.env.development     ⏳ (Ev - Development - Django server) [Henüz oluşturulmadı]
backend/.env.docker          ⏳ (Opsiyonel - Docker özel ayarlar) [Gerekirse oluşturulacak]

Frontend içinde bulunan ENV dosyaları:

frontend/.env.office.dev     ✅ (Ofis - Development)
frontend/.env.production     ✅ (Production - Docker için)
frontend/.env.development    ⏳ (Ev - Development) [Henüz oluşturulmadı]

ORTAM KULLANIMI:
- Ofis Dev: Django server ile çalışır (backend/.env.office.dev + frontend/.env.office.dev)
- Ofis Prod: Docker ile çalışır (backend/.env.office.prod + frontend/.env.production)
- Ev Dev: Django server ile çalışacak (backend/.env.development + frontend/.env.development)
- Ev Prod: Docker ile çalışacak (aynı docker-compose.yml)

Bu dosya isimleri, dizinleri ve ayrım mantığı KESİNLİKLE değiştirilmeyecek.
Yeni env dosyası ekleme, mevcut dosyaları birleştirme veya isim değiştirme YASAKTIR.
Sadece ben bir dosyadaki belirli bir satırı değiştirmeni söylersem değiştireceksin.
